```text

  -> Device.GetDeviceInformation
  -> Device.GetCapabilities
  -> Media.GetProfiles
  -> Media.GetStreamUri
  -> ProvisioningResult 생성
  -> OnvifProvisioningRepository 저장
  -> MediaService.addCamera(results)
  -> CameraManager.add_camera(CameraConfig)
  -> GStreamer ingest/recording 시작
```
